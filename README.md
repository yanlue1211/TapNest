下面保留原点点栖的功能与源码文档供参考（GPT版增加官方 ChatGPT 账号登录、Chat/Work 两种形态语气与小输入框，尚未实现共享外接记忆库）。

## 原版功能说明

# 点点栖 · TapNest 🌱

**轻轻一点，栖在身边。**

点点栖是一款可以在 Android 手机上显示、制作和互动的本地桌面伙伴应用。支持从手机导入自己的 PNG、GIF 和 Codex Pet 素材，也能在手机上给分层角色制作动作。

> **公开预览版 · 测试构建**：目前仍在开发中，并非已发布到应用商店的稳定正式版。Android 8+；不同厂商系统的悬浮窗、锁屏和后台行为可能有所不同。

## 从零制作自己的分层桌宠

选择「创建分层／绑骨桌宠」，从**通用空白模板**开始。没有任何内置私人角色、默认人物立绘或角色贴图，也无需联网生成图片。

- 新建时**只保留身体默认帧**，其余部位自行添加：「左翅膀／右翅膀」「左耳朵／右耳朵」「尾巴」「头部」「自定义图层」；不用在单只与左右一起创建之间选择。已有图层可一键镜像复制另一侧，添加的默认帧可直接删除。
- **真正中轴镜像复制（唯一镜像入口）**：先给左侧部位上传图片并调整骨骼、动作等参数，再点「↔ 镜像复制」，右侧会自动带上所有已设置的参数、图片、动作帧，并在角色画布中轴镜像；修正一左一右反向拍动问题。之后两侧可以独立修改（不自动联动后续参数），也可以直接分别创建左右图层、分别上传素材。
- 图层的**显示名称支持中文**。内部自动生成英文标识作安全的 PNG 文件名，不要求用户输入英文。
- 基础素材页只上传各部位的**默认帧**；额外动作帧在该部位设置里添加。设置页分组折叠，预览拖动默认锁住以防滑动误触，也可一键复位图层位置。
- 支持单独选择骨骼点的移动方向：自动旋转、水平、垂直、反向或固定；可选弹簧惯性、保形和推荐尾巴预设。
- 可在实时预览中隐藏其他部位，单独调整点位。骨骼点位带有简短折叠说明。
- **多形态换装（测试版）**：创建桌宠时先点「创建形态」进入原来的绑骨页面；完成第一形态后进入形态管理，可创建空白形态或复制现有形态（复制全部素材、骨骼、动作帧），每种形态独立修改。原角色身份、位置、缩放和对话数据不变。长按桌宠 **1 秒以上、不足 5 秒并松手**，打开浅绿色换装面板：可一键切换整套外观，也能分别选择耳朵、尾巴、翅膀的来源形态或隐藏部位；保持 **5 秒以上不移动** 直接关闭桌宠；拖动拎起、双指缩放不会误触关闭。旧角色无须迁移就能作为默认形态继续用。
- **长按拎起**：取代难以触发的摸摸头；按住桌宠拖动时，普通图层整体冻结并围绕画布顶部中点轻摇。可以开启专属单张 PNG 模式，只有「开关、上传 PNG、调整整图大小、实时预览」，图片同样围绕顶部固定锚点摇动；松开恢复常态。不需要额外骨骼或定点。
- 图片、对话、角色存档和个人模板保存在设备本地。不会自动上传分享。

**提示：** 动作帧图片需要按部位分别上传，且应与同一角色的默认图层使用一致的透明画布。二维骨骼变形不是三维建模，高幅度动画可能会拉伸轮廓。

## 其他功能

- 导入 PNG、GIF、Codex Pet 角色并作为悬浮桌宠显示，支持拖动、缩放、点触互动。
- 分层角色可单独编辑头部、身体、翅膀、尾巴、耳朵等动作；支持表情和局部换帧。
- 本地互动、预设气泡对话、日程提醒和伙伴小屋；不需要 LLM、API Key 或服务器。
- 支持保存自制模板及本地数据备份。
- **旧数据兼容**：此前已经创建或导入的角色与自定义模板仍可从本机读取；不再向新用户提供原来的私人内置模板创建入口。

## 下载与构建

开发版 APK 可从仓库 [Actions](../../actions/workflows/test.yml) 中选择最近一次 **绿色成功** 的构建，打开 `app-debug`，下载 ZIP 并解压安装。GitHub 可能要求登录账号。

**请注意：** CI 的 Debug 包是测试签名，不保证可以直接覆盖升级另一台机器或另一轮构建的 Debug 包。升级前请先在应用中备份数据；不要为了更新而直接卸载旧版。

在自己的 Android 构建环境中使用 JDK 21 和 Android SDK：

```bash
./gradlew testDebugUnitTest assembleDebug
```

CI 会额外检查 Android lint、仪器测试编译和 APK 构建。自动化测试成功并不代表所有品牌手机上功能都已充分验证。

## 隐私

GPT版请求联网权限：用户主动授权 ChatGPT 后，发送文本和本轮检索的本地聊天上下文到 OpenAI 模型接口。原版预设台词、素材和本地存档不会因为添加 GPT 而自动上传。悬浮桌宠需要 Android 悬浮窗权限及前台服务授权；用户可以主动关闭。
