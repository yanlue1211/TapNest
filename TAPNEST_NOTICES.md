# TapNest distribution and credits

TapNest is a modified version of [DeskPet](https://github.com/faysal-X-N/deskpet).
Its source is governed by the upstream GPL-3.0-or-later license (see LICENSE).
When sharing an APK, provide access to its complete corresponding source and
the applicable copyright/attribution notices; a public source repository with
the matching release tag is the intended distribution method.

This branch does not bundle upstream pet artwork, branding images or generated images.
Users bring their own pictures and character packs and keep them on their devices.
Imported character art is not automatically relicensed under GPL.

KinetiFrame's architecture was reviewed for inspiration, but no KinetiFrame source
code is incorporated in this release.

V0.1 contains no network permission, LLM, image generation, or API-key handling.
Later optional AI capabilities must be opt-in and off by default.
