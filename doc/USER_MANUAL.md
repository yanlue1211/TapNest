# 点点栖 · TapNest 使用手册

- 文档适用范围：截至 **2026 年 11 月 6 日** 的公开测试版功能（对应版本须以 APK 来源页面列出的提交记录为准）。
- 适用设备：**Android 8.0 及以上**。不同品牌的悬浮窗、通知、后台管理可能有差异。
- 本手册只讲当前已有的功能、按钮的意思和如何操作。不需要会写代码。
- 本应用当前**不包含在线 AI 聊天、接入大模型 API、自动生图或云端账号同步**。文字气泡使用本地预设台词；图片、角色和伙伴信息主要保存在手机本地。

## 一、先认识几个词

| 界面用词 | 简单理解 | 什么时候用 |
| --- | --- | --- |
| **APK** | Android 安装包 | 先安装应用 |
| **悬浮窗** | 可以显示在其他 App 上面的桌宠 | 想把角色放在手机屏幕上 |
| **PNG** | 一张普通图片，推荐透明底 | 直接做静态桌宠或绘制分层角色 |
| **GIF** | 会自己播放的动图 | 已经画好了逐帧动作，不想自己绑骨 |
| **Codex Pet** | 一种有规定动作格式的宠物素材包 | 想导入支持招手、跑步等动作的现成包 |
| **图层 / 部位** | 身体、左翅膀、尾巴等分开的图片 | 想让身体局部单独动 |
| **默认帧** | 这个部位平常显示的图片 | 所有分层部位至少从它开始 |
| **动作帧** | 戳一下、眨眼或定时动作时临时替换的另一张图片 | 想做表情或局部变化 |
| **锚点 / 旋转中心** | 一块图片绕着转的固定位置 | 比如翅膀根部、耳朵根部 |
| **骨骼点 / 控制点** | 沿部位摆放的活动控制点 | 做柔软弯曲、尾巴摆动、翅膀上下变形 |
| **父图层** | 当前部位跟随的上一级部位 | 头跟身体走、耳朵跟头走 |
| **镜像复制** | 做好一边后，自动造出左右对称的另一边 | 想两边用同一套点位和参数 |
| **备份 ZIP** | 打包保存你的宠物数据的压缩文件 | 换机或重新安装前保存 |

**最简单的选择：** 只有一张图，就选「自绘 PNG」；已有动图就选「GIF」；想让翅膀、尾巴、呆毛分别动，再选「创建分层／绑骨桌宠」。

## 二、安装、权限与开启

### 2.1 安装 APK

1. 从可信的发布者或本项目 GitHub 构建页面取得 APK。如果下载到的是 ZIP，先解压，找到其中的 `app-debug.apk`。
2. 在手机「文件管理」中点 APK，按系统提示安装。若提示不允许安装未知来源应用，需要在系统设置中允许**当前文件管理器/浏览器**安装。
3. 装好后打开「点点栖」。
4. 第一次打开会有入门说明，点「知道了」即可。

**安装包来源：** 本项目 [Actions 构建页面](https://github.com/yanlue1211/TapNest/actions/workflows/test.yml)，选择**绿色成功**的运行，进入 **Artifacts → app-debug**（可能需要登录 GitHub）。测试包并非商店正式版。

**更新前注意：** 调试版 APK 的签名不一定相同，未必能覆盖旧版。先用「备份全部」导出 ZIP，确认保存到了手机/云盘，再尝试更新；不要为了更新直接卸载，否则本地数据可能丢失。

### 2.2 为什么需要权限

| 权限 | 作用 | 操作 |
| --- | --- | --- |
| **显示在其他应用上层 / 悬浮窗** | 让桌宠出现在桌面及其他 App 上 | 点「开启桌面伙伴」时，按提示打开该权限 |
| **通知（部分 Android 13+）** | 显示桌宠运行中的常驻通知 | 系统询问时按需要选择；拒绝时可能看不到运行通知 |
| **前台服务** | 让桌宠在你切去其他 App 后继续显示 | 由应用和系统管理，无需额外绘制角色 |

各手机的权限位置不同。常见路径是：**系统设置 → 应用 → 点点栖 → 权限 / 特殊权限 → 显示在其他应用上层**。

### 2.3 显示、关闭、保后台

1. 在宠物列表中**点一下**想显示的角色卡片。
2. 展开底部控制区，点「**开启桌面伙伴**」。
3. 角色出现在屏幕上。想停用时点「**关闭悬浮角色**」，或通过系统通知提供的关闭入口停用。

**如果切换应用后桌宠消失：** 先确认悬浮窗权限没有被撤销；再检查省电限制、后台运行、自启动/后台保护等系统设置。不同厂商会主动清理悬浮服务，本应用不能保证所有手机永久保活。系统省电模式下动画可能降低帧率、暂停自主移动。

## 三、首页「桌面伙伴」每个地方是什么意思

| 位置或按钮 | 用途 |
| --- | --- |
| **角色卡片** | 每张卡片代表一位已导入或制作的角色 |
| **点一下角色卡片** | 选中它，供悬浮窗显示；同一时间主要显示一位 |
| **长按角色卡片** | 打开「角色操作」菜单 |
| **重新编辑绑骨** | 只在分层角色上显示；回到已有角色的部位、图片和动作编辑，不需要重新新建 |
| **编辑点击台词 / 💬** | 修改点击角色后出现的文字气泡 |
| **💚 伙伴小屋** | 打开角色的好感度、性格、互动道具、提醒 |
| **删除** | 删除该角色和相应素材；删除前有确认，操作不可撤销，先备份 |
| **卡片角落的导出/分享图标** | 将**这一只**宠物导出为 ZIP，和「备份全部」不同 |
| **底部收纳坞 / 控制区** | 点开后看到开启/关闭、大小控制、导入、帮助、备份 |
| **＋、－** | 小幅调整桌宠在屏幕上的显示大小 |
| **缩放滑块** | 精细调整大小；**100% / 1×** 相关按钮用来回到标准大小 |
| **导入** | 去创建或导入角色、恢复备份 |
| **帮助** | 重新查看内置入门提示 |
| **备份全部** | 把宠物列表及其相关素材打包为 `TapNest_backup.zip` |

**两种“分享”不要弄混：** 「导出」通常指某一只角色的素材包；「备份全部」可能含你的多位角色及伙伴数据，**不要随便把整机备份发给别人**。

## 四、桌面上怎么和角色互动

| 你做的动作 | 角色会怎样 |
| --- | --- |
| **单击** | 分层角色按对应部位的点触设置动作/换帧；普通 PNG/GIF 有轻微弹跳；Codex 素材通常播放招手动作 |
| **长按后移动** | 拖着角色换位置；分层角色进入「拎起」状态 |
| **松开** | 分层角色停止拎起效果、恢复原来的图层与动作 |
| **双指捏合** | 放大/缩小屏幕上的桌宠；与首页大小设置同步 |
| **双击** | 打开伙伴互动面板（如喂食、洗澡、玩耍等），效果视角色类型与配置而定 |
| **暂时不操作** | Codex 格式可自行播放一些预设状态；分层角色的闲置晃动/定时动作取决于你是否开启并配置 |

**注意：** 不同格式的桌宠动画能力不一样。单张 PNG 不会因为单击就长出新动作；想让呆毛突然立起来，需要专门的分层、骨骼或动作帧素材配置。

## 五、「导入宠物」界面：应该选哪一个

1. **创建分层／绑骨桌宠**：多张 PNG 组合为一位角色，独立编辑翅膀、耳朵、尾巴、头部等，也能做局部柔性变形。请看第六～九节。
2. **自绘 PNG（无需分层）**：选一张 PNG 直接导入，适合只想摆着看、点一下弹跳的人。不需要绑骨。
3. **Codex Pet 素材包**：选择含 `pet.json` 和精灵表的标准 ZIP。可以根据素材包播放多种预设动作。
4. **GIF 动图**：直接选择 `.gif` 文件。按 GIF 本来的帧序列播放，不会额外分拆翅膀、尾巴。
5. **恢复备份**：选择此前由点点栖生成的 `TapNest_backup.zip`，用于恢复角色及对应素材。

**没有自带角色图片：** 要使用自己画的图片或有权使用的素材。创建分层角色时，所有部位素材都由用户自己上传。

## 六、分层角色：从零制作一只（第一次建议照着做）

### 6.1 第一次制作的最短流程

1. 点「导入 → 创建分层／绑骨桌宠」。
2. 选择「**🌱 通用空白模板**」。
3. 输入「这只桌宠的名字」。
4. 在「**★ 身体 · 默认帧**」右边点「导入」，选一张透明 PNG。
5. **如果你只有这一张图，到这里就够了。** 身体画面可以直接包含头发、脸、手脚；不必为了“完整”硬建头部和翅膀。
6. 如果你有单独画的翅膀/耳朵等，向下滑到「＋ 自行添加默认部位」，选择对应名称 →「＋ 添加选中的部位」→ 在新部位右边「导入」。
7. 想调动作时，点该部位下的「⚙️ 设置动作／变帧」；做完点「← 返回默认帧素材列表」。
8. 最下方选择是否把布局存为模板，然后点**创建/保存**按钮。完成后从角色列表选中并开启悬浮窗。

**制作时最重要的素材规则：** 各张 PNG 最好使用**同样大小的透明画布**，角色身体、翅膀根部等摆放位置也尽量保持一致。需要运动的部位画在单独透明图层上，空白处保持透明。

### 6.2 「导入图片到对应图层」这一排按钮

- **★ 身体**：唯一必需的默认帧。身体可以是一张完整立绘。
- **导入 / 已选 ✓**：选择或替换当前部位的 PNG。「已选」表示当前已有文件。
- **清除**：只清掉此部位已选图片；图层和动作参数还在，之后可重新导入。
- **删除**：删除这个**部位图层**和它对应的动作帧、设置；身体图层不提供删除。
- **⚙️ 设置动作／变帧**：进入当前部位的独立设置页面。
- **↔ 镜像复制（含动作与点位）**：复制当前部位的图片、骨骼点、旋转中心、晃动/点触参数、已有动作帧等，生成镜像部位。

**「清除」和「删除」不同：** 不满意图片选「清除/重新导入」；整个部位不要了才选「删除」。

### 6.3 「＋ 自行添加默认部位」菜单

| 选择项 | 它代表什么 |
| --- | --- |
| **左翅膀** | 建一个左侧翅膀部位，可以之后镜像复制为右翅膀 |
| **右翅膀** | 从右侧开始单独制作，之后也可以镜像复制为左侧 |
| **左耳朵 / 右耳朵** | 只有耳朵需要单独摆动时才建，不是必填 |
| **尾巴** | 用于摇尾巴、弹簧尾巴等 |
| **头部** | 头需要单独点头或切换表情时再建；整张头画在身体里也可以 |
| **自定义图层** | 例如「呆毛」「蝴蝶结」「发带」，可自己写**中文名称** |

选择之后记得按一次「**＋ 添加选中的部位**」。**下拉框只是选择种类，不是完成添加。**

如果想要两边不一样，直接分别加「左翅膀」「右翅膀」；如果想先做完一边再复制同一套设置，看下一节。

### 6.4 镜像复制：想做两片一起动的翅膀

1. 先添加**左翅膀**，上传图片。
2. 进入左翅膀设置，把**旋转中心、骨骼点、晃动幅度、速度、点触动作**调到满意。
3. 回到默认帧列表，点左翅膀下的「**↔ 镜像复制（含动作与点位）**」。
4. 自动出现右翅膀，并使用**关于角色画布中轴的左右镜像**。复制时会带上原图片、动作帧和已设参数。
5. **两边花纹不一样？** 直接在新生成的右翅膀上重新上传它的 PNG；**不会清除已经复制的点位和晃动设置**。

重要区别：

- 复制完成时，两边的配置一样；**之后修改左边，右边不会持续自动同步**，需要分别修改。
- 另一侧已经存在时，不能再重复生成同名图层，界面会提示。
- 替换右侧图片时，系统仍会将这个**镜像图层**水平翻转。右侧素材建议与左侧采用相同透明画布和根部位置，不要先手动翻一次再被系统翻第二次。
- 更换图片**保留设置**不等于新图片的翅尖坐标永远合适；如果绘制布局差别很大，视觉上仍可能需要微调点位。

### 6.5 「把本次绑骨布局存为以后可复用的模板」

- 开启：额外存一份**图层位置、骨骼、参数等布局模板**，供以后新建角色时选择。
- 关闭：只保存当前角色，不另外创建可复用模板。
- 模板**不包含角色图片**；使用时要重新为对应部位导入 PNG。
- 这是「布局模板」，与「备份全部」不同。当前备份 ZIP 的内容以角色/素材为主，**不要假定布局模板文件已随备份导出**。

## 七、进入「⚙️ 设置动作／变帧」后每一组是什么意思

设置页的功能大多可以**点标题展开 / 再点标题收起**，不需要一次看完。建议一次只展开一组，避免手机上滚动太长或误碰。

### 7.1 顶部：选择部位和中文名称

- **当前：……**：正在编辑的部位。
- **中文图层名**：给它起好理解的显示名称，比如「右边软耳朵」「小呆毛」。只改显示文字，不影响程序内部文件 ID。
- **← 返回默认帧素材列表**：回到可以导入、删除和镜像复制的列表。

### 7.2 🖼️ 实时合成预览

| 控件 | 用法 |
| --- | --- |
| **其他部位** | 开启：连同身体、其他翅膀一起看；关闭：只看当前部位，方便找点位 |
| **解锁拖动** | **默认关闭**，防止上下滑页面时误把图层挪走；要用手拖图层/骨骼时再打开 |
| **移动图层** | 调整当前部位的位置（X/Y），不是调整锚点 |
| **点设锚点** | 在预览中点一下，指定旋转中心 |
| **编辑骨骼点** | 选择和移动骨骼控制点；操作前先添加控制点 |
| **试玩互动** | 在编辑预览里测试已配置的点触、闲置或定时动作，查看有无反向、穿模 |

**最容易混淆：** 「移动图层」动的是**整张部位图片**；「点设锚点」动的是**绕哪里旋转**；「编辑骨骼点」动的是**哪段可以弯曲**。这三个不一样。

### 7.3 🎞️ 动作帧 / 换图设置

一个部位平常只有**默认帧**；这里还可以额外上传**最多 3 张**动作图（动作帧 1、2、3）。

例如：

- 默认帧：呆毛趴着。
- 动作帧 1：呆毛立起来。
- 打开「点触时切换动作帧」，选择**动作帧 1**。
- 点角色时暂时显示竖起来的呆毛，随后回到默认状态。

**上传第二张图不等于自动启用：** 需要在下一组「🎮 点触 / 定时 / 眨眼」明确设置**何时换图、换第几张**。

另外，动作帧不是用来描绘中间动画过程的，每张都是一种可以临时显示的图片；实际切换时是否自然取决于你的素材。

### 7.4 🎮 点触 / 定时 / 眨眼

| 开关或选项 | 作用 |
| --- | --- |
| **启用自定义动作** | 对部分旧版角色显示；旧配置保持原先兼容方式 |
| **点触时晃动本部位** | 点击角色时，当前部位做短暂动作 |
| **点触时切换动作帧** | 点击角色时改显示选定的另一张图；需要先上传对应动作帧 |
| **晃动方式** | 选择**摇头、弹跳、扇动、抖动**等动作类型；名称是预设运动方式，不是一定要有头/翅膀 |
| **点触时显示哪张动作帧** | 选择 1、2 或 3；没有上传相应图片时无法得到预期换图效果 |
| **每隔一段时间自动动作／换帧** | 不用点击，系统定期触发一下 |
| **自动动作间隔（秒）** | 相隔多少秒尝试一次定时动作 |
| **短暂晃动** | 到时间执行一个短动作，不更换图片 |
| **切换动作帧** | 到时间临时显示选定动作帧 |
| **正常静置时偶尔眨眼** | 需要先上传闭眼图片，并选择它对应的动作帧编号 |

**区分两个概念：** 「每隔几秒抖一下」是**定时触发一次**；「闲置时自动晃动」是**没人在碰它时持续摆动**，开关在下面「🌿 绑骨 / 闲置晃动」内。

### 7.5 📍 位置 / 缩放 / 父图层

| 项目 | 含义 | 简单例子 |
| --- | --- | --- |
| **绑定到父图层** | 当前部位跟随谁一起动；「无（独立）」则不挂在别的部位下面 | 耳朵跟着头，尾巴跟着身体 |
| **水平位置 X** | 左右移动整个部位 | 翅膀根部离背部有点远 |
| **垂直位置 Y** | 上下移动整个部位 | 呆毛的位置太高 |
| **旋转中心 X / Y** | 设定旋转支点坐标，范围 0～1（按该图宽高比例） | 翅膀根部是铰链，不应绕翅尖转 |
| **图层原始大小** | 让当前部位图片变大或变小 | 耳朵看起来太大 |
| **前后层级** | 决定遮挡顺序：通常数值较大的图层画在较上方 | 背后尾巴应排在身体后面 |
| **↺ 图层位置复位** | 将**X/Y** 恢复到起始偏移位置 | 不小心拖歪了 |

- **复位只恢复位置 X/Y**，并不一键抹掉锚点、骨骼、大小和全部设置。
- **对本部位应用中轴镜像**：左右翻转此图层。通常镜像复制另一侧时程序会自动处理，无需反复开启。

### 7.6 🌿 绑骨 / 闲置晃动

- **闲置时自动晃动**：开启后，部位在待机时有持续动作。
- **不添加骨骼点**：多用于整片部位绕**旋转中心**晃动，像硬纸片转动。
- **添加 2～8 个控制点**：部位可沿点位分段弯曲，适合尾巴、长耳朵、翅膀。
- **需要软变形**时，再设置下面的「弹簧」「柔软度」「阻尼」「点运动方向」。不必一次把所有开关都打开。

### 7.7 🐾 弹簧参数预设

这是帮你快速填好一套**建议数值**，不用从零猜：

- **🐶 竖直狗尾（粗·半长）**：较粗、从背后翘起的尾巴。
- **🐱 竖直猫尾（细·略长）**：适合细长、弯曲较明显的尾巴。
- **🐶 斜向狗尾（单侧）**：尾巴向身体一侧伸出去。
- **🐱 斜向猫尾（单侧）**：细长且斜向一侧的尾巴。

点「**应用弹簧参数**」是把预设的**晃动参数**应用到当前部位，并不会替你换图片；「**按首尾重排点位**」需要你已经至少标过**起点和终点**，才会尝试重排中间点。

**提醒：** 预设只是起点。如果尾巴真的长在角色左后方，骨骼点位置仍需要自己放准。

### 7.8 🎐 晃动方式和参数：调这些会有什么变化

| 设置 | 数值增大之后通常会怎样 |
| --- | --- |
| **延迟模式** | 前端/后端分段跟随，适合一般柔性摇动 |
| **🌀 弹簧惯性** | 像带惯性的软尾巴，会有跟随和回弹 |
| **左右摆动幅度（度）** | 摆得更大；太大可能穿过身体或扭曲 |
| **晃动速度（次／秒）** | 来回摆动更快 |
| **弹簧柔软度** | 更柔软，尾尖更容易跟随 |
| **回弹阻尼** | 数值低更有弹性感；数值高更快停住 |
| **单侧向外摇晃** | 用于斜向身体一边的尾巴，尽量避免越过中线向内甩 |
| **粗线条保形** | 越大越重视保住图片轮廓；接近 1 更像整片刚性转动 |
| **上段跟随延迟（秒）** | 越大，远离根部的段落反应越晚 |

**第一次调试推荐顺序：** 先开闲置晃动 → 试幅度 → 试速度 → 不够柔软再添加控制点 → 最后再试弹簧/阻尼/保形。每次只动一个参数更容易知道哪里变好了。

### 7.9 🦴 控制点 / 方向 / 骨骼

**从根到尖放点，不要把点沿轮廓胡乱围一圈。**

1. 点「**＋ 添加点位**」。
2. 把**第 1 点 P1**放在部位接到身体的**根部**。
3. 把下一点放到中间，再把尾端/翅尖的点放在**尖端**。
4. 点击点位编号选择当前要调整的点。
5. 通过预览或「点位 · 横向 X / 纵向 Y」改变位置。
6. 用「**第 N 点运动方向**」选择这段怎么动。

方向菜单说明：

| 选项 | 人话解释 |
| --- | --- |
| **自动旋转** | 顺着骨骼原本方向转，适合自然弯曲 |
| **左右 → / 左右 ←（反向）** | 让该段主要向左右运动 |
| **上下 ↓ / 上下 ↑（反向）** | 让该段主要上下运动，翅膀上下扇动时可以先试 |
| **逆向旋转** | 与一般转动方向相反 |
| **固定** | 这段尽量不跟着摆 |

- **删除选中的骨骼点**：只删除选中的一个点，不删除整个图层。
- 点太密容易扭曲；一般先用**根—中—尖三个点**实验。
- 单图二维变形不能把平面的翅膀变成真正三维折翼，动作幅度太大可能拉长/压扁绘制内容。

### 7.10 🎭 表情与情感绑定 / 👀 旧版头部表情

当你使用单独的头部或脸部图层时，部分设置页会显示：

- **表情与情感绑定**：把已有的头部/脸图片对应到平常、开心、不开心、生气、害羞等状态。伙伴小屋中的好感度可能影响当前表情选择。
- **静置眨眼**：指定哪张图片代表闭眼。
- **被戳时表情**：指定点击时的表情图片。
- **旧版头部选项**：部分保存的旧版模板才显示，跟旧素材的四张表情规则有关。

**没单独画头部就可以跳过。** 如果整张脸都画在身体里，不必为了表情菜单专门拆图层。

## 八、🪁 长按拎起效果（单独的一组，和绑骨无关）

**不设置任何东西也能使用：** 长按桌宠移动时，整个角色暂时停止局部动画，以**画布顶部中间**为固定支点左右轻晃；放手后回到原状态。

想让被拎起来时整只角色换个姿势：

1. 在**默认帧素材列表**展开「**🪁 长按拎起效果**」。
2. 打开「**使用专属拎起单图**」。
3. 点「**上传图片**」，选择一张完整的透明 PNG。
4. 用「**拎起图片大小**」调整尺寸。
5. 看下方「**🪁 拎起效果实时预览**」，确认摇摆是否合适。
6. 不需要增加骨骼点、旋转中心或动作帧。关闭开关就恢复使用原来的分层角色整只轻晃。

**这组只有开关、图片上传/替换、大小、预览；不提供其他绑骨与动作参数。** 两种拎起模式都围绕同一个**顶部中心固定点**摇摆。单图模式会在拎起期间临时替代原来全身图层，松手恢复。

## 九、💬 点击台词和 💚 伙伴小屋

### 9.1 点击角色显示气泡

1. 在首页点角色卡片上的「💬」，或长按卡片 →「编辑点击台词」。
2. 「点击时显示文字气泡」开关：决定是否弹出文字。
3. 「预设台词」输入框：**一行一句**，角色每被点一次通常换下一句。
4. 最多约 **20 句**，每句约 **60 字**；可以自己改成吐槽、撒娇或提示语。
5. 点击「保存」。

**它是预设文字，不是模型生成的对话。** 不需要网络或 API Key。

### 9.2 伙伴小屋里的内容

| 位置 | 是干什么的 |
| --- | --- |
| **好感度（0～100）** | 本地互动数值；长期不互动会缓慢下降 |
| **伙伴性格** | 不同性格会影响好感度变化 |
| **🍪 互动** | 选择喂食、洗澡、玩耍 |
| **道具** | 可修改道具名字、Emoji、图片图标、使用时台词 |
| **＋ 添加自定义道具** | 自己创建互动道具 |
| **🎬 本类互动专属动作素材** | 可为当前互动类型上传 PNG 或 GIF；互动时暂时用这张/这段素材显示整只角色，之后自动恢复 |
| **⏰ 备忘录** | 写一句提醒内容并选时间 |
| **提醒时间 `yyyy-MM-dd HH:mm`** | 例如 `2026-11-07 20:30`，注意年月日及 24 小时制 |
| **添加定时提醒** | 保存提醒；到时间可以在正在运行的悬浮宠物上显示气泡 |
| **删除提醒** | 删除该条提醒 |

如果设提醒时宠物没有运行，错过的提醒可能会在下次启动悬浮宠物时显示。提醒功能**不是系统闹钟**，请不要用来承载必须准时触发的重要事项。

## 十、导出、备份和恢复（防止辛苦画的素材丢掉）

### 10.1 只分享一只角色

在首页找到角色卡片右下角的**分享/导出图标**，生成该角色的 ZIP。它用于保存或转移**角色素材**，不是 APK 安装包；发给朋友前先确认图片和台词等个人内容可以分享。

### 10.2 备份全部

1. 展开首页底部控制区。
2. 点「**备份全部**」。
3. 保存系统分享界面提供的 `TapNest_backup.zip` 到文件管理/云盘。
4. 尽量保留一个早期可恢复的副本。

当前备份机制以**宠物列表、宠物素材和各宠物相关的伙伴资料**为主。**自定义布局模板单独保存在应用本地模板目录，不要假设它已包含在 ZIP 内。**

### 10.3 从备份恢复

1. 打开「导入」→「恢复备份」。
2. 选择先前的 `TapNest_backup.zip`。
3. 导入完成后到宠物列表检查图片、动作、台词是否正常。

恢复不等于覆盖所有现有数据；程序会避免重复覆盖已有的相同角色 ID。备份 ZIP 可能含私人素材、人物形象和台词，**不要当成给陌生人的公开素材包随便转发**。

## 十一、常见问题排查

| 遇到的情况 | 先检查 |
| --- | --- |
| **开启后看不到宠物** | 是否选中角色、是否授权「显示在其他应用上层」、是否被系统省电清理 |
| **新角色只有身体、找不到头部** | 正常！新建空白模板只强制身体；到「＋ 自行添加默认部位」按需增加 |
| **下拉选了左翅膀却没出现** | 还需要按「＋ 添加选中的部位」 |
| **点击后呆毛突然立起** | 看呆毛是否有动作帧，以及「点触时切换动作帧」或「点触时晃动」是否启用 |
| **上下滚动编辑页面时图片跟着跑** | 在实时预览里关闭「解锁拖动」；需要调整时才短暂开启 |
| **图层挪歪了** | 到「位置 / 缩放 / 父图层」点「↺ 图层位置复位」；它只复位 X/Y |
| **翅膀绕错地方转** | 去「点设锚点」，把旋转中心放到翅膀根部 |
| **尾巴像硬纸片** | 检查有没有 2～8 个骨骼点、是否开启闲置晃动、是否选择柔性/弹簧 |
| **镜像另一侧后方向/图案不对** | 检查另一侧是否仍是镜像图层；替换 PNG 可能已被手动翻转而又翻转一次 |
| **两边翅膀摆动幅度不一致** | 优先做完一侧再镜像复制；复制后两边不会持续联动，后来修改的数值需要自己保持一致 |
| **换了一张翅膀图片后点位错了** | 配置没有丢；新图片的透明画布尺寸、根部和尖部布局是否与原图一致？ |
| **拎起来后尾巴不动了** | 这是设计：拎起时其他局部动作静止，整只角色以顶部锚点轻摇 |
| **拎起的专属 PNG 没有显示** | 确认「使用专属拎起单图」已开启、PNG 已上传、图片有可见内容 |
| **点击台词不显示** | 检查该角色的气泡开关、是否保存了句子 |
| **导入失败** | 检查是否确实是 PNG/GIF，文件是否过大；Codex ZIP 是否含正确的 `pet.json` |
| **APK 更新失败** | 可能是签名不一致；先备份，不要直接卸载现有版本 |
| **手机卡、发热或耗电明显** | 尝试缩小画布/图片、减少柔性控制点；系统省电也会降低动画帧率 |
