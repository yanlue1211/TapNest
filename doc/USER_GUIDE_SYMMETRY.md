# 点点栖使用手册 · 左右不同的翅膀，如何设置一样的晃动？

## 最省事：先制作一侧，再镜像复制

1. 创建桌宠，导入**身体默认帧**。
2. 在「自行添加默认部位」选择**左翅膀**（也可以先选择右翅膀）。
3. 给左翅膀导入 PNG，然后进入「设置动作／变帧」，摆好旋转中心、骨骼点位（从根到尖）、摆动幅度、速度、点触以及自动动作，并试玩。
4. 返回素材列表，在左翅膀下点击 **↔ 镜像复制（含动作与点位）**，得到右翅膀。它会复制全部已设置的运动参数与动作帧、图片，并让右侧相对角色中轴镜像。
5. **两边翅膀不同？** 在右翅膀的「导入／替换图片」里选择第二张 PNG 即可。**动作参数、骨骼点位和旋转中心不会被重置。** 若动作帧也不同，进入右翅膀的「动作帧 / 换图设置」逐张更换。

**素材注意**：为了无需重新调整点位，两张 PNG 应使用**同一尺寸的透明画布**，翅膀根部、尖部等关键位置在源图中的坐标尽量相同。右侧属于镜像图层，绘制时会自动水平翻转你上传的图片；因此用于替换的右侧素材最好仍按左侧素材的源图方向绘制，只改变纹样／颜色／轮廓。如果导入一张已经人工水平翻转的 PNG，会被再次翻转；如果两张图根、尖位置不一样，点位虽然不会丢失，视觉效果仍可能需要微调。

**保持两边晃动幅度一致**：镜像完成时，两边已具有相同的幅度、速度、骨骼点位置和动作设置。后续若单独调整其中一侧，另一侧不会自动改变，要按需手动设置同样的数值。

## 左右翅膀都独立上传

分别选择「左翅膀」和「右翅膀」创建独立图层，分别上传 PNG 并调整参数。适合两边形状／布局差异较大、不适合直接镜像时使用；独立创建不会自动复制另一侧的骨骼设置。更想省力时，优先选上面的**左翅膀 → 镜像复制 → 更换右翅膀图片**。

耳朵等成对部位也适用。已经存在独立右侧图层时，无法再在同一名称上镜像复制，先创建一个对应侧的部位再进行镜像复制。
