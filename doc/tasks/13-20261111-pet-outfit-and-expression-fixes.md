# 2026-11-11 · 点点栖桌宠体验修复说明

## 已合入源码（以主分支实际提交为准）

1. **顶部空白画布**：对 PNG 和分层桌宠测量首次实际渲染像素的顶部透明占比，悬浮窗的 Y 最小值扣除这段透明画布，改善拖动至屏幕顶部时头部仍距离安全区域很远的问题；可见像素仍受系统安全区限制。
2. **按角色实际素材显示的换装配件**：不再固定展示耳、翅、尾；会读取每套形态实际保存的 PNG，支持 `part_1`「蝴蝶结」等自定义图层自动纳入菜单，可选择「不佩戴」或在多个形态间更换，且不删除原图、绑骨与动作帧。旧 rig 未增加必填字段，默认值兼容旧存档。
3. **眨眼与定时动作/表情争用**：定时动作优先于闲置眨眼，统一 overlay 与 editor 预览。修复旧版交替帧没有继承当前可见头部条件，造成多个表情帧叠加的问题。
4. **Live2D 独立导入模式规划**：不强制转 PNG，不合并到绑骨编辑器；官方 Cubism Core 属于单独许可组件，需合法获取 SDK 且实现真实播放后才发布可用的导入入口。详见 `11-live2d-isolated-import.md`。

本次修复不修改已有用户角色数据。首次从旧临时 debug 签名升级到固定签名仍必须先确认完整备份，不能直接覆盖；升级方案见 `doc/apk-upgrade.md`。
