# 公开版素材说明

当前 TapNest 公开版 APK **不内置任何角色立绘、翅膀、尾巴、眼睛、表情图片或私人角色模板**。

通用模型创建器仅提供空白图层、示例动作数值和骨骼编辑工具。用户在自己手机中选择 PNG、GIF 或角色包后，图片数据仅保存在本机的应用私有目录。

从早期项目迁移来的示例和历史外部角色素材已经从当前工作树及 APK 中清除。Git 历史为履行上游项目归属与许可证要求而保留；历史版本的资产权利状况不应被当作当前公开版的素材授权。

请勿将第三方角色、未获授权的贴图或商标图形打包进对外发布的 APK。

软件的源代码采用 GPL-3.0-or-later；由用户独立导入的图片不因使用此应用而自动适用该代码许可证。发布规范请参阅 [TAPNEST_NOTICES.md](../TAPNEST_NOTICES.md)。
