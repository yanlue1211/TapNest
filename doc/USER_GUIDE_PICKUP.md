# 点点栖使用手册 · 长按拎起桌宠

**如何操作？** 在桌面悬浮桌宠上长按，然后拖动移动；松开后放回原来的待机动画。以前「在头部水平搓动触发摸摸头」的入口已删除，以免与长按移动争抢手势。

## 默认拎起：普通图层整只轻晃

无需设置。长按进入拎起态后，**整只桌宠以画布顶部正中间为固定锚点，统一左右摇晃**。翅膀、耳朵、尾巴等其他小动作会暂时静止，避免一只宠物同时执行很多动画。松开后恢复原有动作。这个默认摇晃无需骨骼点位，不会改变其他部位原有的骨骼与互动设置。

## 上传自己画的拎起姿势（可选）

进入「制作桌面伙伴」的素材列表，展开「🪁 长按拎起效果」：

1. 打开开关「使用专属拎起单图」。
2. 上传一张完整的、独立的透明 PNG（不用为这张图建立动作帧或骨骼）。
3. 唯一允许调整的图像参数是 **拎起图片大小**，可以直接在页面下方看摇晃预览。
4. 拎起来时原来的所有部件和动画隐藏，直接显示这张 PNG；**同样使用画布顶部中间这个固定锚点左右晃动**。放下后正常角色和原有动作回归。

这块界面**仅提供开关、图片导入／替换、大小和实时预览**；不提供额外绑骨、动作帧、旋转点位置或特殊表情设置。

**注意**：建议使用与身体图相同尺寸的透明画布，并在画面顶部合适的位置绘制悬挂点。图片尺寸调整是以顶部正中点为轴缩放。开关关闭时会恢复默认全身轻晃；已上传 PNG 会保留，下次可以重新开启。
